# Implementation Plan: Arogya AI Doctor Interface & Clinical Dashboard

Extend the existing **Arogya AI** application to add a comprehensive, professional **Doctor Interface** (Doctor Dashboard, Case Queue, and Case Details View) that consumes and visualizes intake data generated by the Patient Interface, while preserving the existing patient intake workflow and visual language.

---

## User Review Required

> [!IMPORTANT]
> **Zero Disruption to Patient Flow**:
> - The existing Patient Interface (`LandingPage`, `InterviewPage`, `CompletionPage`) remains 100% intact.
> - Navigation between Patient and Doctor views will be managed through state without forcing React Router, using a clean top-level view switch (e.g. `viewMode: 'patient' | 'doctor'`) accessible via a dedicated "Doctor Portal" button on the header and return links on the Doctor side.
> - When a patient completes an interview in the Patient Interface, that case will be automatically available in the Doctor's intake queue alongside pre-populated mock cases.

> [!NOTE]
> **Clinical Safety & Legal Disclaimers**:
> - AI outputs are explicitly tagged as assistive.
> - Red flags will be worded as *"Potential red flag detected — requires prompt review"* rather than definitive disease diagnoses (e.g., no "Dengue detected").
> - Red colors are strictly reserved for safety-critical alerts.
> - Missing clinical history fields will display *"Not reported"* rather than being fabricated.

#### [NEW] [mockCases.js](file:///C:/Users/user/Downloads/ArogyaAI-Patient-System/src/data/mockCases.js)
- Centralized store for patient cases.
- Provides realistic clinical cases (e.g., `Ramesh Kumar` with `MED-94021` showing high fever and chills with red flags; `Priya Sharma` with `MED-81204` showing acute viral symptoms; `Vikram Singh` with `MED-63119` showing respiratory symptoms with hypertension history; `Sunita Patel` with `MED-52018` showing acid peptic disease).

  - `chiefComplaint`, `hpi`, `redFlags` array
  - `aiSummary` (Chief complaint, HPI, severity, associated symptoms, medications, medical history, allergies, reports, red flags, verification disclaimer)
  - `structuredHistory` (Chief complaint, HPI, past medical history, medications, allergies, family history, personal history, review of systems, investigations)
  - `messages` (full dialogue transcript matching patient chat structure)
  - `reports` (uploaded documents with mock OCR extracted lab values such as Hemoglobin, Platelet count, WBC, with status `Within reference range` / `Outside reference range`)
  - `doctorNotes`, `provisionalDiagnosis`, `reviewedAt`

#### [NEW] [DoctorContext.jsx](file:///C:/Users/user/Downloads/ArogyaAI-Patient-System/src/context/DoctorContext.jsx)
- Central state manager for the Doctor Interface.

6. **Medical Report & OCR Section**: Shows attached reports (e.g. `CBC_Haemogram_Report.pdf`), upload timestamp, and OCR extracted parameters with `"Outside reference range"` / `"Within reference range"` labels.
7. **Doctor Clinical Notes & Assessment**: Text area for physician remarks, provisional diagnosis field (clearly separate from AI), and "Save Notes" / "Accept Case" actions.
